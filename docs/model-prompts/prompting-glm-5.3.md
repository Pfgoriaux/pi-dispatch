# GLM-5.3 prompting choices

Bound the investigation to the requested behavior and evidence standard. Cite
files and symbols for code claims, distinguish inference from verification, and
report evidence gaps rather than inventing answers. Do not turn a focused task
into an unsolicited repository survey.

This matches the scope-bounding approach in
[Aliou's implementation](https://github.com/aliou/pi-harness/commit/f3394b52e7b77be847c98f550e525b775225c878).
It is a local heuristic, not a measured claim about all GLM variants.

Provider reference: [Z.ai thinking documentation](https://docs.z.ai/guides/capabilities/thinking).
This extension does not set thinking, sampling, or tool-loading parameters.
